BLACKWATER CIÉNAGA 3D: 12 smuggler runs through the Leonida wetlands — airboat + truck, gator water, 5-star LWMP dispatch, FOGHORN-1 spotlight heli, roadblocks, 3 crew, dock workshop, dusk-to-dawn cycle. Rook Calloway, ex-airboat tour guide turned smuggler, runs contraband through the Blackwater marsh for Mama Odette — outrun the Wildlife & Marine Patrol, dodge the gators, and move the whole stash before the dawn levee raid. A fictional moonlit wetland with stilt houses, reed beds and a levee town; a from-scratch WebGL1 low-poly renderer (no library, no download); on-foot + airboat + truck; crew abilities; dock workshop upgrades; respect ranks; circular minimap; WebAudio synth SFX and 3 procedural radio stations; localStorage saves; deterministic seeded world.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080
```

WASD drive/walk · Shift sprint · Space handbrake · E enter/exit vehicle, start jobs, advance dialogue · G workshop (at Mudskipper Dock) · M missions · Q radio station · 1/2 crew abilities · F spotlight · R back on the road · Esc pause. Screenshots: `?shot=1` chase, `?shot=2` town, `?shot=3` gators, `?shot=4` dawn finale.
